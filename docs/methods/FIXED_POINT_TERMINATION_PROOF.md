# 有限静态输入上的固定点终止性说明

设初始显式图为有限图`G0`。TC-SSSAO的R1—R8与B1—B5均为正向、加事实的CONSTRUCT规则，迭代满足`G_i subseteq G_(i+1)`；R9—R18执行一致性/数据验证，不创建无限领域个体。派生资源IRI由源事实、事件域、快照身份和状态的稳定哈希决定，因此同一组源事实重复执行不会生成新IRI。

对固定的有限输入图，规则体可匹配的源元组组合有限；类、属性和规则头模板也有限，故所有规则可能产生的不同三元组集合`D(G0)`有限。单调链`G0 subseteq G1 subseteq ... subseteq G0 union D(G0)`不可能严格增长无限次，因而存在有限`k`使`G_k = G_(k+1)`。

该证明只针对一次有限静态输入。它不意味着所有规模固定若干轮收敛，也不处理持续到达数据的撤回语义。50事件RDF图本次观测的新增量为`[300, 0]`；7个规模档均在生成轮后以一次零新增检查确认固定点，即观测为2轮。迟到快照通过受影响`event_id`局部删除并重算B3边处理，不将单调物化误称为通用Truth Maintenance System。
